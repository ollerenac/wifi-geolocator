The station-to-capture workflow

  1. Name the station. Record P1, its latitude/longitude and reported accuracy. Keep the computer stationary during capture.
  2. Record AP metadata. A validated receiver records timestamp, BSSID, SSID if advertised, frequency and per-frame RSSI. Repeat across planned channels.
  3. Join and review. Import each capture with its station ID. Review count, span, time bins, spread and consistent receiver settings.
  4. Estimate per AP. Use three or more usable positions with sufficient geometry. Calibrate separately and compare with known AP references.

No live SDR decoder is connected to this demo. The current B210 power probe cannot create these AP metadata files. Read the acquisition design and file contracts.
