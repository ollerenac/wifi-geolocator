## Signal and compatibility limits

Legacy OFDM a/g/p only, not DSSS/CCK b. A 2.4 GHz hotspot can send incompatible
beacons despite supporting OFDM data. Verify actual beacons; 5 GHz is a useful
next test if phone and antenna permit it. No promise of all present SSIDs.

52 active LS tones, unnormalized 64-point FFT:
10log10(sum(abs(CSI)^2)/64^2). This is noisy averaged LTF relative power, not
full-packet/channel-average RSSI. ltf_power_dbfs, snr_db and absolute dBm remain
separate. rssi_dbm empty unless measured matching profile supplied. Current
demo-1 is dBm-only and rejects relative collector files. Explicit relative-power
model support requires later schema/UI work; never relabel dBFS or guess offsets.
Host decode-receipt UTC includes buffering/processing delay; TSF is not UTC.
CRC failure count unknown; duplicate window 4096; no detections is not absence.
