A repeatable first experiment

  1. Calibrate separately. Measure the selected BSSID at several known distances, using fixed receiver gain, antenna orientation and AP settings.
  2. Collect at four stations. Record GPS and its accuracy, timestamp, channel, repeated AP-specific RSSI samples and optional true bearings.
  3. Estimate without the answer. Compare the overlap with three stations, then add the fourth. Check whether the region shrinks and contains the reference.
  4. Repeat and report failures. Evaluate position error, region area, reference containment and sensitivity to calibration. A missing overlap is a result to investigate.

The B210 probe reports aggregate dBFS power. It cannot populate AP-specific RSSI in dBm. This demo accepts manual / imported metadata; live Wi-Fi collection is a separate hardware step. Read the methodology and CSV format.
